> Generated by `node selfcheck.mjs --sync-keys`. Do not edit by hand.
> `selfcheck.mjs` fails when this inventory, the two dictionaries and the keys referenced by `app.js` drift apart.

- key 命名：`<domain>.<object>.<action|state|field>`，全小写点分（`docs/03-architecture.md` 第 6 节）。
- 双向覆盖率必须是 100%：切到 en 后界面 0 条中文残留（K-10）。
- 渲染出来的节点都会带 `data-i18n="<key>"` 与 `data-i18n-lang`，因此"界面残留中文"可以机器断言，不靠人眼。
- 新增文案的顺序：先加 `zh.json` + `en.json` → `node selfcheck.mjs --sync-keys --sync-embed` → 在 `app.js` 用 `t(`key`)` 引用。
