# 06 真实用户实测反馈表（模板 v1.0）· TraceLens 行动透镜

> **这份文件是给"真实用户实测"用的空白模板**，不是已经填过的反馈。
> 走查脚本、主持人口径与"SUS 计分规则"见 [05-real-user-kit.md](./05-real-user-kit.md) 第 5–6 节；
> 本表是它的**可单独打印/单独回传的版本**（一场实测一份）。
>
> 重要：`docs/05-test-report.md` 里的数据来自**模拟走查**（团队成员扮演用户），
> 不是真人测试。只有本表被真实用户填过，才叫"真人实测"。

---

## 0. 主持人怎么用这张表（3 步）

1. **发**：把表（前半部分"用户填写"）发给用户，连同对应形态的安装包/网址与一句话任务说明。
2. **陪**：用户在操作时你在旁边**只看不说**，把他卡住的地方原话记在"观察"栏；
   除非超过 3 分钟完全无法推进，否则不提示。
3. **收**：填完收回，把"故障"栏单独摘出来建 issue；本表归档到 `docs/06-feedback/`（自建目录）
   或团队的反馈表里，**不要**把真实姓名/邮箱写进本文件（用编号 U1/U2…）。

## 6. 开放题（写原话就行，别修饰）

1. 第一次打开时，你以为这是什么？现在你觉得它是什么？
2. 有哪句话你**没看懂**？请把那句话抄下来：____
3. 有哪个按钮你**找不到**？当时你想做什么：____
4. 如果只能保留一个功能，你留哪个？为什么？
5. 你最担心它出什么事？（例如把不该做的事做了 / 记录被人看到 / 数据丢了）
6. 你会怎么向同事介绍它？（一句话）
