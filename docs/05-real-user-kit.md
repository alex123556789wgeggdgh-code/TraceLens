## 3. 路径 0：源码预演（现在就能跑）

### 3.1 启动服务

1. 打开 PowerShell，进入仓库根目录（把路径换成你本机的；当前工作副本在 `E:\DEEPSEEK 黑奴\agent-explainer`，路径含空格/中文，必须加引号）：
   ```powershell
   cd "E:\DEEPSEEK 黑奴\agent-explainer"
   python --version
   ```
   预期 Python 3.10 以上（本机实测 3.14.7）。没有 Python 就先装 Python 3.12+，安装时勾选“Add python.exe to PATH”。
2. 启动本地服务（**记录、审计、设置都写到临时目录**；记录会持久保存）：
   ```powershell
   $env:QA = "$env:TEMP\TraceLensQA"
   New-Item -ItemType Directory -Force $env:QA | Out-Null
   python -m agent_explainer.server --port 8765 --records-store "$env:QA\records.jsonl" --audit-log "$env:QA\audit.jsonl" --settings "$env:QA\settings.json"
   ```
   预期控制台打印：`TraceLens API http://127.0.0.1:8765/`、`records: 12 条演示数据`、`records store: ...`、`audit: ... 追加式 JSONL 链校验通过`。**保持这个窗口开着**。
3. 另开一个 PowerShell 验证健康检查（可选但推荐）：
   ```powershell
   Invoke-RestMethod "http://127.0.0.1:8765/health" | Select-Object status,mode,version
   ```
   预期 `status=ok`、`mode=local`、`version=0.5.0`。
4. 浏览器打开：`http://127.0.0.1:8765/`。

### 3.2 启动成功的标志

- 顶部有横幅“合成演示数据 · 非真实采集”；
- 三区：**待确认 4 / 进行中 1 / 已完成 7**（4 条都可决定；0011 显示“超时了”，状态 expired 仍可迁移）；
- 每张卡片有一句人话，右侧有“演示数据”徽标；
- 顶部有中文/English、刷新、实时状态；左侧栏有“设置 / 审计记录 / 导出审计 / 导入数据”。

### 3.3 停止服务

在服务窗口按 `Ctrl+C`；确认端口释放。不要直接关电脑了事（会留下后台进程）。

## 4. 三种正式形态（5.5 起产物已就绪）

> 5.5 前的口径是“可能没有产物、没有就记 BLOCKED”。现在三种形态都有真实产物（桌面在 `release/`，
> 镜像与离线 tar 在 `release/0.5.0/`，总包在 `release/tracelens-0.5.0-release/`），
> 照下面做即可；**不要**再用源码预演冒充安装形态。
> 装机前请先核对哈希与签名（第 12 节命令），三者对得上再开始计时。
>
> **0.5.0 交付文件名**：`TraceLens-0.5.0-win-x64-Setup.exe`、`TraceLens-0.5.0-win-x64-portable.exe`、
> `TraceLens-0.5.0-win-x64-portable-src.zip`、`tracelens-0.5.0-image.tar`、镜像标签 `tracelens:0.5.0`。
> 装机前请把 exe 放到**纯 ASCII 路径**（中文路径会触发 NSIS `Error writing`）。

### 4.1 路径 A：Windows 安装包

1. 核对文件：`release/TraceLens-0.5.0-win-x64-Setup.exe`、`release/SHA256SUMS.txt`、`release/TraceLens-SelfSigned.cer` 在同一目录。
2. 算哈希并比对（`SHA256SUMS.txt` 是 CRLF 写的；PowerShell 逐文件比对最省事）：
   ```powershell
   (Get-FileHash ".\TraceLens-0.5.0-win-x64-Setup.exe" -Algorithm SHA256).Hash
   # 期望 37cf69638a21368631eaccee3cb7c180a365f6b4265ecbd25ac7747a60e0395d（逐字取自 release/SHA256SUMS.txt）
   (Get-AuthenticodeSignature ".\TraceLens-0.5.0-win-x64-Setup.exe").Status
   # 期望 UnknownError（自签名：签名落了，但根证书不受信任；见 release/SIGNATURE-STATUS.json）
   ```
   与 `SHA256SUMS.txt` 中该文件的值一致才继续。
3. 双击安装。预期出现 SmartScreen“Windows 已保护你的电脑”——这是**自签名**的正常现象，不是病毒；点“更多信息 → 仍要运行”。（若公司电脑禁止，改用便携版。）
4. 从开始菜单启动；**计时 T0→T1**（双击到首屏可见）。预期 ≤5 分钟。
5. 卸载：设置 → 应用 → TraceLens → 卸载；确认无残留服务/端口。

### 4.2 路径 B：便携版

1. 把 `release/TraceLens-0.5.0-win-x64-portable.exe` 拷到空目录（例 `C:\TraceLensPortable`，路径别带中文）。
2. 双击这一个 exe；计时 ≤3 分钟看到首屏（首次运行会先解压自身，稍慢）。
3. 数据**不在 exe 旁边**：便携版与安装版一样落 Electron 用户数据目录（默认 `%APPDATA%\<应用名>\data`，应用名取 `desktop/package.json` 的 `productName`）；想固定位置就设环境变量 `TRACELENS_DATA_DIR`。
4. 退出后整个目录删掉即可；不要删系统里的东西。
   说明：`desktop/build/dist/TraceLens-0.5.0-win-x64-portable-src.zip` 是**源码便携包**（需要系统 Python），
   不是这个 exe；别混用。

### 4.3 路径 C：Docker compose（团队模式）

> 真实编排文件是**仓库根**的 `docker-compose.yml`（不在 `docker/` 子目录）；先做 `docker info`，不通过就停。
> 详细步骤、FAQ、备份升级见 `docs/05.4-docker.md`。

1. **前置硬闸门**（必须先做）：
   ```powershell
   docker version
   docker info
   docker compose version
   ```
   任一失败：**停止**，记录完整错误与退出码；不要用“YAML 能解析”代替。
2. 在**仓库根**准备 `.env`（只放测试口令，不提交、不截图）：
   ```powershell
   cd "E:\DEEPSEEK 黑奴\agent-explainer"
   Copy-Item scripts\env.example .env
   # 编辑 .env：TRACELENS_ADMIN_PASSWORD=TraceLens-QA-2026!（≥10 位即可）
   ```
3. 启动（**仓库根**执行；镜像已在本地时不会重新构建）：
   ```powershell
   docker compose up -d
   docker compose ps
   ```
4. 健康检查：
   ```powershell
   Invoke-RestMethod "http://127.0.0.1:8765/health" | ConvertTo-Json -Depth 4
   ```
   预期 HTTP 200、`status="ok"`、`mode="team"`、`auth.required=true`、`audit.durable=true`。
   （健康检查路径是 `/health`；没有 `/api/health`，也没有 `ready` 字段。）
5. 浏览器打开 `http://127.0.0.1:8765/`；用 `admin` + 上面的口令登录（首次登录会要求改密）；
   确认“需要我”里有待确认卡片。
6. 持久化：记下审计条数/用户；`docker compose restart`；复查审计/用户/记录是否还在。
   5.4 已实测：`records.jsonl` 43,486B → 43,486B、记录条数不变、用户表与审计链都活过重启。
7. 收尾：`docker compose down`（保留 `./data` 与 `./logs`）；删除 `.env` 里的口令（别把 `.env` 交回去）。

## 9. 故障排查（先看这里，别硬试）

| 现象 | 可能原因 | 怎么办 |
|---|---|---|
| `python` 不是内部或外部命令 | 没装 Python / 没加 PATH | 安装 Python 3.12+ 并勾选 Add to PATH；或改用安装包 |
| 端口被占用 | 8765 已被别的程序用 | 换端口：`--port 8766`，浏览器同步改 |
| 页面空白/转圈 | 服务没起、URL 错、缓存 | 看服务窗口是否报错；确认 `http://127.0.0.1:8765/`；Ctrl+F5 |
| 看不到“设置/审计/导入” | 窗口宽度 <1024px，左侧栏被隐藏 | 最大化浏览器窗口；或按 F11 全屏；手机用「更多」 |
| 登录页一直转 | team 模式但服务没起好 | 看控制台 admin 口令是否打印；确认 `/health` 200 |
| 管理员口令丢了 | 只打印一次 | 停服务、删除 `$env:QA\auth.json` 后重启（仅测试环境）；**不要**猜口令 |
| 审计文件找不到 | 启动时没带 `--audit-log` | 源码默认写 `var/audit.jsonl`；本套件用 `$env:QA\audit.jsonl` |
| `docker info` 失败 | Docker Desktop 没启动/WSL2 未装 | 停止，记录错误，请发起人安装/启动；不要用静态检查代替 |
| SmartScreen 拦截 | 自签名，正常 | 核对 SHA256 与签名指纹；更多信息 → 仍要运行；公司电脑改用便携版 |

| 中文变成问号 | PowerShell 请求体编码 | 中文操作走浏览器；API 用 Python（UTF-8），不要用 `Invoke-RestMethod` 发中文 |

## 10. 隐私、清理与诚实边界

### 10.1 隐私

- 只用合成演示数据；不要粘贴真实客户内容、真实邮箱、真实密钥。
- 如果误贴了真实数据：立即停止，删除 `%TEMP%\TraceLensQA` 与相关截图，并告知测试负责人。
- 审计的“理由”是自由文本；4.8 起会对其中的邮箱/手机号做脱敏，但**仍不要**在理由里填真实个人信息。
- 截图/录屏只发给测试负责人；不要发群、不要上传网盘。

### 10.2 清理

```powershell
# 停服务后执行；确认路径就是你的临时目录
Remove-Item -Recurse -Force "$env:TEMP\TraceLensQA"
```

- 安装版：用卸载程序；便携版：删目录；Docker：`docker compose down`（卷按需保留）。
- 不要删除仓库里的 `samples/`、`docs/`、`tests/`。

### 10.3 诚实边界（写进回传）

- **n=1**：你的体验是定性信号，不是统计结论；不要写“大多数用户”。
- **源码预演 ≠ 安装验收**：K-01 的安装包/便携版计时必须等 t12 产物；Docker 必须等 t17。
- **记录持久**：4.9 起记录写 `records.jsonl`，重启仍在；但 Docker 卷重启仍需 t17 实测。
- **决定 ≠ 生效**：你点同意/拒绝只保证“决定已记录”；是否真的执行取决于执行端是否接入。
- **演示数据是合成的**：不是真实采集，不能当真实证据对外。
