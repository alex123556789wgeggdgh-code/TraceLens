# 06 用户手册（非技术版）· TraceLens 行动透镜

> 这份手册写给**不懂技术**的人：不用看代码、不用懂日志，照着做就能用起来。
> 每个技术词第一次出现时都会解释一次，最后一节还有"小词典"。
> 遇到问题先翻 [06-faq.md](./06-faq.md)；要反馈问题用 [06-feedback-form.md](./06-feedback-form.md)。
>
> 版本 0.5.0 · 适用形态：Windows 安装包 / 便携版 / 团队网页版（Docker）

---

## 1. 它到底帮你做什么

你让 AI 助手去干活，它会在你电脑或服务器上留下一堆"流水账"（技术叫 **trace**，就是"轨迹/记录"）。
那些记录只有工程师看得懂。**TraceLens 把这些流水账翻译成一张人话清单**，回答四个问题：

1. 它**做了什么**？（一句话，不用点开）
2. 它**为什么这么做**？（点开才有）
3. **现在要不要你拍板**？（要，就会出现在"待确认"区）
4. 你该**点哪个按钮**？

还有一件重要的事：**它不会替你做决定，也不会假装你的决定已经生效。**
你点"同意"，系统只记录"你同意了"，并把它写进一份**不能事后修改**的账本（审计）。
真正执行的那一端有没有照做，要看它自己的"回执"；没报就是"未上报"，界面不会骗你说"已强制停止"。

## 2. 先装上（三种方式选一种）

| 你手上是什么 | 怎么做 | 需要 |
| --- | --- | --- |
| 一个 `TraceLens-0.5.0-win-x64-Setup.exe` | 双击 → 按向导下一步 → 开始菜单里点 TraceLens | Windows 10/11 电脑 |
| 一个 `TraceLens-0.5.0-win-x64-portable.exe` | 放到一个你能写、**路径里没有中文**的文件夹（例如 `D:\TraceLens`）→ 双击 | 同上，**不用安装** |
| 同事给了你一个网址（例如 `http://192.168.1.20:8765/`） | 浏览器直接打开，用同事给你的账号登录 | 和服务器在同一个网络 |

**第一次打开 Windows 可能弹蓝色警告**（"Windows 已保护你的电脑"）——因为这个包是我们自己签的名，
Windows 还不认识这张证书。点**"更多信息"→"仍要运行"**。
（它只证明"文件没被改过、出自我们"，不代表"微软认证的软件"。）

第一次启动会自动放 **12 条演示数据**，让你先看懂界面。这些是**编出来的假数据**，
顶部会有一条"演示数据"横幅，每条记录也有小徽标——换成真实数据后，横幅和徽标会自动消失。

## 3. 界面上你只需要认识三样东西

### 3.1 三个区（从上到下）

| 区 | 里面是什么 | 你要做什么 |
| --- | --- | --- |
| **待确认** | 只有 **1 件**：现在最需要你拍板的事（其它的显示"还有 N 件在排队"） | 看一句话 → 点开详情 → 同意 / 改参数 / 拒绝 |
| **进行中** | 正在跑、还没结束的 | 一般不用管，看进度就行 |
| **已完成** | 已经结束的（成功 / 失败 / 被你拒绝的都在这里） | 事后翻账、导出证据 |

颜色是固定的：**绿=完成、黄=进行中、红=失败、蓝=等你、灰=拒绝或跳过**。

### 3.2 一张卡片

- 默认**只有一句人话**（例如"要把 512 字节写进相册的 all.md，需要你确认"）；
- 右下角"**展开详情**"点开，才有：分步说明、花了多少时间/多少钱、用了什么工具、参数是什么、
  执行端回执是什么；
- 卡片右上角如果有"演示数据"小徽标，说明这条是假的样例。

### 3.3 顶栏（或手机上的「更多」）

| 入口 | 你能做什么 |
| --- | --- |
| 语言切换 | 中文 ⇄ English，**不会丢任何记录** |
| 审计记录 | 看"谁在什么时候做了什么决定"，以及账本有没有被改过 |
| 导出审计 | 导出 CSV（Excel 能开）/ 可打印页 / PDF |
| 导入数据 | 粘贴一段 JSON 或选一个文件，把过去的记录导进来 |
| 设置 | 模型配置（可选）、界面语言、数据管理 |
| 用户管理 | 团队模式下加人、改角色、停用（**不能删除**，因为审计要追得到人） |

手机上这些入口都在**顶栏右侧的「更多」**里；按钮是灰的说明你没这个权限或没连上服务，
旁边会**直接写原因**（不是"点了没反应"）。

## 4. 十分钟上手（跟着做一遍就会）

**第 1 分钟**：打开界面，看到 12 条演示卡片 + 顶部演示横幅 → 随便点一张卡片看"一句话"。

**第 2 分钟**：点"展开详情" → 看它为什么这么做、花了多少、执行回执是什么。

**第 3 分钟**：找到"待确认"区那 1 件 → 点"同意这个方案"（或改参数 / 拒绝）。
注意：操作后卡片会进入"已完成"区，**审计里多了一条记录**（这就是"决定 ≠ 生效"的边界演示）。

**第 5 分钟**：打开"审计记录" → 你会看到刚才那条决定（时间、谁、哪件、决定、哈希短码）。
再点"刷新"，看它是不是还在（在，因为账本只追加）。

**第 7 分钟**：点"导出审计" → 选 CSV → 用 Excel 打开，看一眼内容。

**第 8 分钟**：点"导入数据" → 把 `samples/traces/mcp_events.json` 的内容粘进去 → 导入
→ 清单里多出 9 条（12 → 21 条），新的这几条**没有**"演示数据"徽标。

**第 9 分钟**：切到 English → 界面变英文、演示数据也变英文、**刚才导入的 9 条还在**；切回中文。

**第 10 分钟**：关掉程序再打开 → 你导入的那 9 条**还在**（记录已经落盘）。

## 5. 日常五件事

### 5.1 看"现在要我拍板的是什么"

打开就看"待确认"区那 1 条。看完点开详情，再决定。

### 5.2 同意 / 改参数 / 拒绝

三个按钮的含义：

- **同意**：就按它原本的计划做；
- **改参数**（例如把 512 字节改成 128 字节）：系统会记录"你改了什么"，原计划也会留着；
- **拒绝**：不做，并写清原因（有些场景要求必须填理由）。

点完不用等"生效"，它只承诺"你的决定被记下了"。执行端有没有照做，看卡片的**执行回执**。

### 5.3 想知道"它为什么这么干"

点"展开详情"：分步说明是给人看的第二层；更技术的第三层（工具名、参数、耗时、指纹）也在里面，
但你可以完全不看。

### 5.4 把过去的记录导进来

两种都行：**粘贴**一段 JSON 文本，或**选一个文件**（支持 Langfuse 导出、OTel GenAI、MCP 事件流、
本产品的原生记录格式，它会自动认）。
上限：一次最多 64 KB / 200 条；超过会直接提示，不会偷偷截断。

### 5.5 事后拿证据

"审计记录 → 导出"：CSV（Excel）、可打印页（浏览器 Ctrl+P 存 PDF）、PDF（服务器装了 PDF 组件时）。
导出的内容里，邮箱/手机号/身份证号之类的个人信息会被**自动打码**（变成 `<redacted:email#sha256:…>`），
这是设计，不是错误。

## 6. 手机怎么用

- 手机浏览器打开同一个网址（团队版）→ 顶栏右侧「更多」→ 六个入口都在；
- 点记录 → 底部面板从下往上滑出，三个区都在里面；
- 按钮是灰的：说明你这个账号没权限，或没连上服务，旁边写着原因；
- 手机上也能**切换语言、看审计、导入数据、导出审计、改设置**（有权限的话）。

## 7. 我的数据在哪？怎么备份？

| 形态 | 数据位置 | 备份方法 |
| --- | --- | --- |
| 安装版 | Electron 用户数据目录下的 `data`（默认 `%APPDATA%\<应用名>\data`；应用名取 `desktop/package.json` 的 `productName`） | 关掉程序 → 整个 `data` 文件夹复制走 |
| 便携版 | **同上**（便携版与安装版共用同一个用户数据目录，不在 exe 旁边） | 同上；想固定位置就设环境变量 `TRACELENS_DATA_DIR` |
| 团队版（Docker） | 服务器上 `agent-explainer/data` | 拷走这个目录；细节见 [05.4-docker.md](./05.4-docker.md) 第 7 节 |

`data` 里有四样东西：**记录**（`records.jsonl`）、**审计账本**（`audit.jsonl`）、
**设置**（`settings.json`）、**账号与令牌**（`auth/`、`ingest/`）。
**审计账本不要手改**：改一个字节，系统就会判定"账本被篡改"，之后所有导出都会拒绝（这是故意的）。

## 8. 出问题了怎么办

| 现象 | 先试这个 |
| --- | --- |
| 双击没反应 / 一闪就退 | 换到"便携版"试；或右键"以管理员身份运行"；把 [06-feedback-form.md](./06-feedback-form.md) 的故障栏填好发给我们 |
| 打开是空白页 | 等 5 秒（首次启动要起服务）；还不行就看第 3 节末尾的办法，或反馈时附上截图 |
| 登录提示"用户名或口令不对" | 确认大小写；连续 5 次错会锁 15 分钟（等一会儿即可） |
| 登录后要求改密码 | 正常：初始口令必须换成只有你知道的 |
| 导入报错 | 看提示里的原因（空内容 / 不是合法 JSON / 太大 / 格式不认识）；一次别超过 64 KB、200 条 |
| 导出的 PDF 打不开 | 服务器没装 PDF 组件时会自动给"可打印网页"，用浏览器 Ctrl+P 存成 PDF |
| 手机上找不到设置/审计 | 点顶栏「更多」；灰色按钮旁边写着原因（没权限 / 没连上） |

更完整的问题清单在 [06-faq.md](./06-faq.md)。

## 9. 小词典（一句话解释）

| 词 | 一句话解释 |
| --- | --- |
| trace（轨迹） | AI 助手干活时留下的流水账，工程师才看得懂 |
| ActionRecord（动作记录） | 我们把一条流水账翻译成的一条"人话记录"，是界面上的一张卡片 |
| L1 / L2 / L3 | 同一件事的三种详细程度：一句话 / 分步说明 / 技术细节 |
| 审计（audit） | 一本"只追加、不能改"的账：谁在什么时候做了什么决定 |
| 哈希链 | 给账本每一页盖一个和上一页有关的章；改任何一页都会露馅 |
| 令牌（token） | 给机器用的临时钥匙，只能上报数据，拿不到你的账号权限 |
| 回执（receipt） | 执行端回话"我到底做没做"；没回话就显示"未上报" |
| Docker / 容器 | 把程序连同运行环境打包成一个"盒子"，服务器上一条命令就能跑 |
| 卷（volume） | 容器外面的一个文件夹，容器删了数据还在 |

## 10. 三件请不要做的事

1. **不要手改 `audit.jsonl`**（审计账本）——改了就等于毁掉证据，系统会判定篡改。
2. **不要把管理员口令发在群里/工单里**——团队版请用 `TRACELENS_ADMIN_PASSWORD` 环境变量注入，
   登录后立刻改成只有你知道的口令。
3. **不要把数据目录放到共享网盘上做"多人同时用"**——本产品是单进程设计，多人请用团队版（Docker），
   一人一个账号。
